# Custom 3D Stadium Models Directory

If you download the 3D model from Sketchfab:
https://sketchfab.com/3d-models/narendra-modi-stadium-low-poly-game-ready-7f0338a0665f45bc87185393560cb8b0

Place your downloaded `.glb` file here as either:
- `narendra_modi_stadium.glb`
OR
- `stadium.glb`

The game's `GLTFLoader` will automatically detect, load, scale, and render it inside the 3D match!
If the file is not present, the game automatically renders the authentic procedural Narendra Modi Stadium.
