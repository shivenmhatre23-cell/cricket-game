# Custom 3D Models Directory

## 1. Stadium Model (Narendra Modi Stadium)
Sketchfab URL:
https://sketchfab.com/3d-models/narendra-modi-stadium-low-poly-game-ready-7f0338a0665f45bc87185393560cb8b0

Place your downloaded `.glb` file here as either:
- `narendra_modi_stadium.glb`
OR
- `stadium.glb`

## 2. Player Character Model (Indian Cricket Player Rigged)
Sketchfab URL:
https://sketchfab.com/3d-models/indian-cricket-player-rigged-a1001b602e4f430bb9de68c24d9a4aa7

Place your downloaded `.glb` file here as either:
- `indian_cricket_player.glb`
OR
- `player.glb`

The game's `GLTFLoader` will automatically detect, load, and integrate it into the 3D match!
If the files are not present, the game automatically renders the authentic procedural Narendra Modi Stadium and procedural Indian Cricket Player models with custom faces, jersey numbers, and team kits.
