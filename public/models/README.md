## 2. Player Character Model (Indian Cricket Player Rigged)
- **Sketchfab URL:** https://sketchfab.com/3d-models/indian-cricket-player-rigged-a1001b602e4f430bb9de68c24d9a4aa7
- **Author:** numaan.k99
- **License:** Creative Commons Attribution (CC BY 4.0)
- **Asset Files:**
  - `indian_cricket_player.glb` (normalized runtime asset)
  - `indian_cricket_player_rigged.glb` (original downloaded file)

### Model Features & Specifications:
- **Architecture:** 10 SkinnedMeshes (~7,106 vertices)
- **Skeleton:** 83 humanoid Mixamo/Ready Player Me bones
- **Scale:** 1.856m height (1:1 Three.js world scale)
- **Orientation:** Forward along +Z, Y-up, feet at Y=0
- **Opt-in Setting:** Toggleable via **Settings Menu → Player Character Model**:
  - `PROCEDURAL (HD KITS & FACES)`: Default procedural system with individual player faces and custom jersey numbers.
  - `RIGGED 3D GLB (BETA)`: Uses independent `SkeletonUtils.clone` instances of the rigged 3D model with team jersey/pants tinting and 3D back jersey number badge.
